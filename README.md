# SSG6000 FQC 演示系统

SSG6000 系列射频信号源出厂质量检验（FQC）的本机演示应用。演示已完整实现里程碑 4：可运行骨架、员工登录、30 项质检清单、提交入库、记录详情、记录筛选与冒烟测试。

## 环境要求

- Node.js 24
- macOS（本机演示）

## 启动

```bash
npm install
npm start
```

打开 http://127.0.0.1:3780 。

开发时可使用自动重启：

```bash
npm run dev
```

冒烟测试会临时启动一个服务、使用临时数据库并自动清理：

```bash
npm run smoke
```

## 质检流程

`/inspect` 是按 SOP 整理好的 30 项检查表，共 7 个章节：

1. 检验准备与工位环境规范
2. 系统信息与 BOM 结构核查
3. 静态外观与机械结构检查
4. 自动化脚本性能测试
5. 出厂文件清理与底层配置校准
6. 选件授权、出厂复位与硬件自检
7. 外观防护、包装与系统过站流程

每个检查项都有固定 key，勾选状态与标签快照会随记录一起入库。页面顶部的吸附进度条实时显示 `已勾选 / 30 项`；每个章节可一键勾选本节全部项目。

提交规则：

- 合格：30 项必须全部勾选，否则返回 422 并提示补检，不写库。
- 不合格：必须填写 2 到 200 字的原因，即使 30 项全部勾选也记为不合格。
- SN 必填，长度 1 到 64 字；工单号与机型选填，最长 64 字。
- 开始时间取服务端下发的时间，超出最近 24 小时或超过当前时间 1 分钟时改用服务器当前时间；完成时间始终取服务器时间。
- 提交成功后跳转到该条记录的详情页。

## 合格卡

合格记录的详情页会显示「检验合格卡」，内容包含 SN、工单号、机型、检验结果、检验标准、检验员、开始时间与完成时间。

「复制合格卡」按钮使用 `navigator.clipboard.writeText`，不可用时回退到选中文本加 `document.execCommand('copy')`，复制成功或失败都会显示提示。不生成 PDF，也不提供下载。

## 质检记录

`/records` 按完成时间倒序排列，最多显示最近 50 条匹配记录。每行包含 SN、机型、工单号、结果、检验员、完成时间、用时与详情链接。

筛选使用普通 GET 表单提交到 `/records`，服务端按以下规则匹配：

| 参数 | 匹配规则 |
| --- | --- |
| `sn` | 去掉首尾空格后的子串匹配，不区分 ASCII 大小写，最长 64 字符 |
| `work_order` | 同 `sn`，匹配工单号 |
| `model` | 同 `sn`，匹配机型 |
| `result` | `pass` 或 `fail`；其他值按全部结果处理 |
| `from` / `to` | `YYYY-MM-DD`，按完成时间的 UTC 日期闭区间筛选；格式无效时忽略该条件 |

筛选条件会回显在表单中，点击「清除筛选」返回 `/records` 查看全部记录。列表上方显示当前匹配到的记录条数。

空库且没有筛选条件时显示「暂无质检记录」。有筛选条件但没有匹配结果时显示「没有符合条件的记录」，并提供清除筛选入口。两种空状态都返回 HTTP 200。

## 路由

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/login` | 登录页，已登录时跳转首页 |
| POST | `/login` | 校验账号密码并创建会话 |
| POST | `/logout` | 退出登录并清除会话 |
| GET | `/` | 工作台首页，需要登录 |
| GET | `/inspect` | 30 项质检表，需要登录 |
| POST | `/inspect` | 校验并保存质检记录，需要登录 |
| GET | `/inspections/:id` | 质检记录详情与合格卡，需要登录 |
| GET | `/records` | 记录列表，支持 `sn`、`work_order`、`model`、`result`、`from`、`to` 查询参数，需要登录 |

未登录访问受保护页面会跳转到 `/login`。不存在的记录 id 返回 404 页面。

## 数据库

默认数据库位于 `data/ssg6000.db`，首次启动时自动创建 `data/` 目录。数据库启用 WAL 模式，同目录可能出现 `-wal` 与 `-shm` 文件。所有建表语句使用 `CREATE TABLE IF NOT EXISTS`，里程碑 1 的数据库可直接升级。

| 表 | 用途 |
| --- | --- |
| `users` | 员工账号、bcrypt 密码哈希、显示名与角色 |
| `sessions` | 登录会话，8 小时过期 |
| `inspections` | 一次整机检验：SN、工单号、机型、检验员快照、开始与完成时间、总结果、不合格原因、总项数与已勾选数 |
| `inspection_items` | 每条记录 30 行逐项状态：目录 key、章节 key、标签快照、`checked` 为 0 或 1 |

`inspection_items` 以 `(inspection_id, item_key)` 为主键，检查项标签在提交时写入快照，后续目录文案调整不会改写历史记录。记录按完成时间建立索引，详情页的逐项结果按 SOP 目录顺序展示。

## 已知限制

- 列表最多返回 50 条匹配记录，没有分页。
- 完成日期按 UTC 日划分，与本机时区可能相差一天。
- 大小写折叠对 ASCII 标识符可靠，非 ASCII 字符按原样比较。
- 文本筛选使用 `LIKE` 子串匹配，没有全文索引，记录量大时查询会变慢。
- 安全措施仅适合本机演示，详见下方安全说明。

## 演示用途与安全说明

本项目仅用于内部演示，不是生产系统：

- 使用 HTTP 明文，会话 Cookie 未启用 `secure`，只适合本机访问
- 内置演示账号与弱密码
- 没有 CSRF 防护、登录限流、审计日志与权限分级校验
- 请勿部署到公网或用于真实产线数据

正式系统需要 HTTPS、强制密码策略、CSRF 防护、登录限流与完整的权限控制。
