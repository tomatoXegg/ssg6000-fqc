01

检验准备与工位环境规范

1.1 辅助仪器与台面设备状态确认

主测示波器 (SDS5000X)：保持通电开机，后面板 USB 通信线与工控测试电脑保持稳定连接。
辅助示波器 (SDS1054X)：平时必须保持关机断电；若开机，必须拔除后部 USB 线（防止脚本误抓从机）。
工装治具与保护耗材：准备独立选件 U 盘、标准普通 U 盘、射频黑色胶帽、提手防拆封签。
PROHIBITED · 绝对禁忌：摆放余量与防指纹氧化

1. 严禁徒手触摸后盖板：绝对禁止直接用裸手直接触摸后盖板金属表面！人体手汗及油脂极难擦除，极易造成后盖板金属表面氧化生锈、变色发乌，导致整机外观降级不合格。

2. 机身后部必须留足空间余量：请将待测机稍微向工作台操作外侧平移，确保机器后部有充裕的接线插拔空间。严禁死折、大角度挤压射频线缆与测试网线，过度弯折会导致精密射频线内部微波同轴结构损伤，影响高频测试精度并严重折损昂贵线缆寿命！

02

第一阶段：系统信息与 BOM 结构核查（工单比对）

2.1 系统登录与工单检索

鼎阳云平台样机扫码：品质检查 → 整机工序检查 → 样机查询，扫待测机二维码调出生产信息。
数磊 MES 工单 BOM 查询：生产管理 → 工单序号查询 / BOM 信息扫描查询，使用 Ctrl + F 调出物料图纸。
新老款后盖板辨识：老款 1 个 U 型孔位，新款 2 个 U 型孔位。若投老料装新款，必查工单“生产备注”代用批准。
SN 与硬件 ID 比对：通过 \Windows 2-236 下的 SN-ID uploader 扫码，核实机身 ID 与云平台 100% 吻合。
CRITICAL · 新老后盖板核查准则
严格以工单投料为准。如果工单投料编码为老款，但实际机身装配了新款，必须第一时间查阅工单中的“生产备注”是否有工程代用/变更批准说明；无说明者不可擅自放行。
03

第二阶段：静态外观与机械结构检查（断电状态）

在接电前，逐项完成以下结构点检：

后盖板与螺丝：整机 18 颗固定螺丝齐全锁紧；严禁徒手触摸后盖板。
前面板与面膜：丝印清晰无断线无划痕；提手面板贴合平整，无气泡翘边。
四个机身脚垫：手动轻晃四个底座脚垫，螺栓必须紧固锁死，桌面放置平稳无晃动。
接口螺母与接地端子：后面板 BNC/SMA 螺母拧紧；接地端子螺栓锁紧且打扣到位。
开关按键朝向：核对开关按键圆点（○ 标识）方向是否符合标准（进入 2245 查样机色图确认）。
风扇网罩铆钉与 OCXO：铆钉必须完全冲压平整贴合，无凸起翘边；确认带 A 系列标配 OCXO。
04

第三阶段：自动化脚本性能测试（网络配置与核心避坑）

SPECIFICATION · 师傅私授：专机网口通信模式
SSG6000 系列质检自动化脚本采用 LAN 网口通信连接，而不是 USB 连接待测机！车间已固定统一网段与配置规范，若按常规机型插 USB 跑脚本将极难适配驱动。

4.1 待测机静态 IP 配置（每次跑机前必查）

待测机静态 IP 设置：按 Utility → Interface，关闭 DHCP，IP 设为 10.11.20.155，子网掩码 255.255.255.0，网关 10.11.20.1。
# 鼎阳 SSG6000 专用质检静态网络配置参数 IP Address : 10.11.20.155 # ⚠️ 必须严格设为 155，不可填 154 等其他任何地址 Subnet Mask : 255.255.255.0 Gateway : 10.11.20.1
PROHIBITED · 致命避坑红线：测试项勾选规则
在脚本测试项界面点击【全选】后，必须手动取消勾选【网口设置 / LAN Test】！
致命原因：生产调试已对网口进行全功能测试；若质检脚本勾选测网口，脚本会自动改写待测机网络参数，导致当前 .155 通信连接瞬时断开，测试直接崩溃中断！
脚本测试项取消勾选网口：全选测试项后，必须手动取消勾选【网口设置 / LAN Test】，防通信中断。

10MHz 外参考与外部调制换线测试：按提示连接 SDG6052 信号源与示波器 CH1，测试通过。

RELEASE CRITERIA · 两大已知“假报错”识别与放行规则

1. U 盘接口测试报错 (USB Test Fail)：属于自动化脚本底层通信已知 Bug，测试有较大概率误报测不过。判定放行规范：只要质检员进入待测机本地文件系统，能确认看到 3 个 U 盘挂载图标，即代表物理端口完好，直接判定合格放行，该项不上传云端不良。

2. 外调制测试偶发跑不过：属于已知测试环境时序 Bug。在确认硬件接线完全无误的情况下，无需反复拔插重复测试，已与工程师确认报备，直接放行进入下一步。

05

第四阶段：出厂文件清理与底层配置校准

开机次数重置联动清理：重置开机次数后，系统自动清空调试临时垃圾文件，无需逐一手动删除。
常驻系统快照文件确认：清空后每十来秒自动生成的覆盖配置文件属于正常底层快照，无需理会。
交付波形目录核实：打开 82A-1/IQ 模型文件夹，逐一点数确认必须为 8 个文件。
波形文件夹容量核实：属性容量大小必须锁定为 261.77 MB（若缺失必须找小胖重灌）。
06

第五阶段：选件授权、出厂复位与硬件自检

6.1 选件（Option）重置与 U 盘插拔铁律

拔掉所有普通数据 U 盘，只能单独插入专用选件 U 盘，进入 Utility → Option 点击重置恢复试用或正式授权。

⏱️ 选件固化 60 秒倒计时器

重置点击后必须插满 1 分钟！若小于 1 分钟拔出，底层授权固化失败，设置彻底白费！

60s

6.2 Utility 出厂设置全面复核

Factory Reset：执行工厂出厂复位（复位后检查网口是否恢复默认）。
系统语言与屏保：语言设为 English；屏保设 10s 验证息屏正常后关闭屏保。
自启动与时间：关闭通电自动开机；校准系统时钟与北京时间误差在 ±5 分钟以内。
日志清空与 MAC：进入 Log List 全部清空；核实以太网 MAC 地址芯片正常（尾号 74）。

6.3 运行整机自检程序 (Self Test)

LED & 按键旋钮：运行 LED Test 确认 Mod/RF 灯变色点亮；Key Test 全键通过。
Board Test & 风扇：硬件自检显示全部 Pass；手感确认后侧/侧面散热风扇正常运转出风。
07

第六阶段：外观防护、包装与系统过站流程

接口保护与封签：前后面板所有暴露射频头与 BNC 口套上黑色橡胶保护帽；提手左侧贴防拆易碎标签。
数磊 QCS 系统过站：FQC 检验 → 扫描选 LPN → 全选项目 → 批量合格 → 审核确认。
8S 扣机挂载与云平台填单：扫描序列号回车挂载成功；在鼎阳云平台填报电子出厂检查单并留存版本。
